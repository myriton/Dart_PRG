## Запуск
1. перейти в папку проектов **cd..(имя папки)**
2. клонировать репозиторий **git clone (репозиторий)**
3. перейти в проект **cd (название проекта**)
4. открыть в VS Code **code .**
5. установить зависимости: **dart pub get**
6. запустить: **dart run**

## Что изучили
1. Наследование: создание дочерних классов на основе базового класса Character с помощью ключевого слова extends
2. Абстрактные классы и методы: создание шаблона Character, который нельзя инстанцировать напрямую, и объявление метода attack() без реализации, обязательного для всех наследников
3. Переопределение методов : изменение поведения методов родителя в дочерних классах 
4. Вызов родительской логики: использование super(...) для вызова конструктора родителя и super.метод() для дополнения логики базового класса
5. Полиморфизм: работа с объектами разных классов через общий тип Character 

## Ответы
1. Это класс-шаблон, который не может иметь собственных экземпляров. Нельзя создать Character(), потому что в реальности нет просто персонажа, и потому что у него нет реализации абстрактного метода attack()
2. super вызывает конструктор родителя для инициализации его полей. Если его убрать, код не скомпилируется, так как Dart требует обязательной инициализации полей родительского класса 
3. attack() в родителе абстрактный, поэтому мы реализуем его с нуля. takeDamage() в родителе уже имеет логику; мы переопределяем его, чтобы добавить расчет брони, а затем через super.takeDamage() вызываем базовую логику родителя, чтобы не дублировать код
4. Это полиморфизм. Во Flutter это повсеместно: например, метод build() возвращает тип Widget, но реально может возвращать Text, Container или Column — любой класс-наследник
5. Это приватное поле
